===================================================================
                       PDF ANTI PLENGER
         Software Otomasi Split & Rename PDF PO Growell
===================================================================

Aplikasi ini sudah 100% PORTABLE dan SIAP PAKAI di komputer mana pun!
TIDAK PERLU INSTALL Node.js atau software tambahan apa pun.

-------------------------------------------------------------------
CARA MENGGUNAKAN (UNTUK TEMAN / PENGGUNA BARU):
-------------------------------------------------------------------
1. Extract file zip ini ke folder mana saja (misal di Desktop atau Downloads).
2. Double-click file aplikasi utama:
   👉 "PDF_Anti_Plenger.exe"

   - Server akan OTOMATIS MENYALA dalam 1 detik.
   - Halaman browser otomatis terbuka ke: http://localhost:4321
   - Jika ingin mematikan aplikasi, cukup tutup jendela aplikasi atau klik [STOP SERVER].

3. Cara Pakai di Browser:
   - Langkah 1: Klik kotak "Pilih Berkas" atau Tarik file PDF PO ke dalam kotak.
   - Langkah 2: Klik tombol besar "Mulai Split & Auto-Rename PDF".
   - File hasil split otomatis tersimpan rapi di folder:
     📁 Documents\anti plenger

4. Selesai! File PO kamu langsung terpecah per halaman dengan nama:
   [NOMOR PO] [KOTA].pdf

-------------------------------------------------------------------
TOMBOL PINTAS & FILE PENDUKUNG:
-------------------------------------------------------------------
- PDF_Anti_Plenger.exe        : Aplikasi utama (1x klik langsung jalan & buka browser)
- Jalankan_PDF_Anti_Plenger.bat : Alternatif via command prompt
- Hentikan_Aplikasi.bat      : Matikan server paksa jika port masih tersangkut
